Containers — lifecycle

docker run -d -p 8080:80 --name web nginxCreate + start in background (-d), publish host 8080 → container 80, name it
docker ps / docker ps -aList running / all containers (incl. stopped)
docker stop webGracefully stop (SIGTERM, then SIGKILL)
docker start webStart a stopped container again
docker rm webDelete a stopped container
docker logs webShow the container's stdout/stderr

Images

docker imagesList local images
docker pull nginx:alpineDownload an image from a registry
