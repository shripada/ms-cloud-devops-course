Docker Glossary

The words this course uses, and only these meanings.

TermMeaning
ImageAn immutable, layered package of files, binaries, libraries and config needed to run a container. A template, not a running thing. docs
ContainerAn isolated process (plus its filesystem) started from an image. Shares the host's kernel. docs
LayerOne set of filesystem changes (add/modify/remove files). Images are stacks of layers.
RegistryA server that stores and distributes images (e.g. Docker Hub).
TagA human label on an image version, e.g. nginx:1.27. Default is latest.
Docker daemonThe background service (dockerd) that actually builds and runs containers. The docker CLI just talks to it.
Port publishing-p HOST:CONTAINER — forwards a host port into a container port.
Virtual machine (VM)Emulated computer running its own full OS and kernel. Heavier than a container.
